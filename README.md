# 2026CSAE100 — Lecture Games

One self-contained HTML game per topic for **Computational Thinking with Programming** (SCSET, Bennett University). Played from QR codes in the lecture decks. Hub page: [index](https://2026csae100.github.io/lecture-projects/).

| Session | Game | File |
|---|---|---|
| Lecture 5 · Conditional Statements | The Bouncer | `bouncer.html` |
| Lecture 6 · Nested Conditions & Debugging | Fix the Line | `fix-the-line.html` |
| Lecture 7 · Lists, Nested Lists & Tuples | Pick the Box | `pick-the-box.html` |
| Lecture 7 · Lists, Nested Lists & Tuples | Guess the Output | `guess-the-output.html` |
| Lecture 8 · Strings | Slice the Word | `slice-the-word.html` |
| Lab E4 · String Slicing & Methods | Method Match | `method-match.html` |
| Lecture 9 · The while Loop | Guess the Number | `guess-the-number.html` |
| Lecture 9 · The while Loop | Trace the Loop | `trace-the-loop.html` |
| Lecture 10 · The for Loop | Times Table Sprint | `times-table-sprint.html` |
| Lecture 10 · The for Loop | Range Finder | `range-finder.html` |
| Lab E5 · Loops Practice | Loop Duel | `loop-duel.html` |

Each game is a single file with no dependencies — add a game by uploading its `.html` and adding one card to `index.html`.
